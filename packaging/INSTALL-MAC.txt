Nova for macOS
==============

1. Drag Nova into the Applications folder.

2. The first launch is blocked by Gatekeeper, because this app is not signed
   with a paid Apple Developer ID. To get past it:

   macOS 15 (Sequoia) and later:
       Double-click Nova, then click Done on the warning. Open
       System Settings -> Privacy & Security, scroll down to Security,
       and click Open Anyway next to the line about Nova. Confirm with
       your password or Touch ID, then click Open Anyway once more.

   macOS 14 and earlier:
       Right-click (or Control-click) Nova  ->  Open  ->  Open

   Do this once for each version you download. Double-clicking works
   from then on.

3. Nova asks for an NVIDIA API key on first run. It is free:
   https://build.nvidia.com  ->  sign in  ->  profile menu  ->  API Keys.
   The key starts with "nvapi-" and is shown only once, so copy it straight
   away. Nova saves it to ~/.nova/.env

4. Two macOS permissions are needed for the full feature set. macOS will
   prompt the first time each is used, or set them in advance:

   System Settings -> Privacy & Security -> Accessibility
       Lets Nova control windows, the mouse and the keyboard.

   System Settings -> Privacy & Security -> Screen Recording
       Lets Nova see your screen.

   Tick Nova in both lists, then restart it.

   From v5 on, every release is signed with the same certificate, so macOS
   keeps these permissions when you update. Coming from v4 or earlier, give
   them once more: if Nova already looks ticked, remove it from the list
   with the - button and add it again.

   The Permissions button at the top of Nova's window shows where you stand:
   green when both are on, red when one is missing. Click it while it is red
   and it opens the right page in System Settings.

Nova runs commands on your Mac. By default it asks before anything that
changes something. Keep that on until you trust it.
