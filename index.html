Nova

An agent that does what you tell it.

What it does

Tell it what you want in plain English and it works out which tools to use and carries it out. No scripting, no macros to record.

  • Runs commands — launches apps, manages processes, queries your system
  • Handles files — reads, writes, searches, organises, renames in bulk
  • Searches the web — looks things up and reports back
  • Sees your screen — reads dialogs, errors, whatever is in front of you
  • Drives applications — clicks real buttons by name, not guessed pixels
  • Remembers — notes your preferences between sessions

Setting it up

  1. Install it. On Mac, drag Nova to Applications, then right-click → Open the first time. On Windows, unzip and run Nova.exe.
  2. Get a free key at build.nvidia.com — sign in, open your profile menu, choose API Keys. It starts with nvapi- and is shown only once.
  3. Paste it into the window Nova shows on first launch. That is the whole setup.
  4. Mac only: allow Accessibility and Screen Recording under System Settings → Privacy & Security, so it can control windows and see the screen.

Before you run it

Nova runs real commands on your computer. By default it stops and asks before anything that changes something, showing you the exact command first.

Leave that confirmation on until you trust it with the kind of work you are giving it. It is driven by a language model, and language models are sometimes wrong.
